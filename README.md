# 🕵️ Operação Stealth 2D — Repositório Base

Projeto base desenvolvido em **Python + Pygame** para a atividade prática de **Versionamento e Colaboração com Git e GitHub**.

## 🎮 Controles
- **Setas** ou **WASD**: Movimenta o agente (quadrado verde).
- **R**: Reinicia a partida após vitória ou captura.

## 🎯 Objetivo do Jogo
1. Pegar a **chave amarela** sem encostar no **guarda vermelho**.
2. Alcançar a **porta azul** para escapar.
